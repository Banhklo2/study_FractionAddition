# ✍️ [프로그래머스 실전 코드 연습] 분수의 덧셈

프로그래머스 코딩테스트 실습 문제(분수의 덧셈)를 풀면서,  
어려운 코드(실전형 로직)를 직접 끝까지 구현해보는 연습을 목적으로 만든 저장소입니다.  

---

## ✅ 목표

- 분수 덧셈 로직을 **직접 설계 → 구현 → 검증**까지 해보기
- 단순 정답 제출이 아니라, **실전에서 자주 나오는 처리(통분/약분/예외 케이스)**를 코드로 정리하기

---

## 🧩 문제 요약

두 분수 `numer1/denom1`, `numer2/denom2`가 주어졌을 때,

1. 두 분수를 더한 값으로 분자를 계산하고
2. 분모를 통분한 뒤
3. 결과를 **기약분수(더 이상 약분되지 않는 형태)**로 만들어
4. `[분자, 분모]` 형태로 반환한다.

---

## 🔍 핵심 로직 포인트

- **통분**
  - `numer = numer1 * denom2 + numer2 * denom1`
  - `denom = denom1 * denom2`
- **기약분수 만들기 (약분)**
  - `gcd(분자, 분모)`(최대공약수)로 나눠서 약분
  - `numer /= gcd`, `denom /= gcd`

---

## 🛠 사용 기술 / 키워드

- Java
- 최대공약수(GCD) (유클리드 호제법)
- 산술 로직 구현 + 예외 케이스 고려

---

## ✍️ 회고

이 문제는 겉보기엔 단순해 보여도,  
막상 “통분 → 약분(기약분수) → 반환 형식”까지 깔끔하게 처리하려면  
**로직을 정확히 나누고 검증하는 습관**이 필요하다는 걸 느꼈습니다.

앞으로도 프로그래머스 문제를 풀 때  
“답만 맞추기”보다 “실전 코드처럼 직접 구현해보기”를 목표로 연습할 예정입니다 🔥
